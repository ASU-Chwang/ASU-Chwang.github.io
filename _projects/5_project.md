## Overview

This project focuses on image processing techniques for remote sensing satellite imagery.

The research investigated spatial resolution enhancement, image restoration, point spread function estimation, motion estimation, and image stabilization methods for improving the visual and quantitative quality of remote sensing images.

## Research Topics

- Remote sensing image processing
- Satellite image processing
- Spatial resolution enhancement
- Image super-resolution
- Image restoration
- Point spread function estimation
- Motion estimation
- Image stabilization
- Image enhancement

2011–2014
